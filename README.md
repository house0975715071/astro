# 西洋占星 免費星盤（網頁版）

輸入生日、出生時間與出生地，就能在手機或電腦上排出西洋占星的本命星盤，並用圖表看懂自己比較偏向哪一面：

- **三大主星**：太陽、月亮、上升星座，一眼看到
- **星盤輪盤**：十二星座環、十二宮、行星位置與相位線（純 SVG，手機也看得清楚）
- **五大面向雷達圖**：事業、財運、家庭、感情、健康，形狀往哪邊凸，就是你比較有優勢的方向
- **十二宮能量星狀圖**：十二個宮位的強弱一眼可比，點任何一宮看詳解
- **行星表、相位表**：每顆行星的星座、度數、宮位、逆行與尊貴；相位依容許度排序
- **人生週期時間軸**：木星回歸、土星回歸、天王星對分等年齡段，標出你現在走到哪
- **適合的工作**、**今年行運**（木星、土星）、**語音解說**（用你裝置內建的語音念）
- **完整報告**：可列印或存成 PDF；預設不顯示生日、出生時間、出生地

- 星盤是認識自己的一個角度，不是預言，也不是保證；重大決定請配合實際狀況、專業意見與家人共識。
- 健康、心理相關內容只是傾向提醒，不能取代醫師或心理專業的診斷。若你正處於情緒低潮，可撥打衛福部 1925 安心專線（24 小時免付費）。
- 分數是為了讓強弱一眼可比，不是吉凶的絕對值。
- 出生時間會決定上升星座與十二宮；不知道出生時間時改用太陽盤（太陽星座當第一宮）估算，跟正式排盤會有出入。
